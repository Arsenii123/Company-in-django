CRM для сервісного центру

Статус: підтримка. Готовність: 100%.

Проєкт запущено, команда супроводжує його та додає нові функції за запитами клієнта.

Цього тижня

  • Завершуємо тестування API для служби доставки.
  • Готуємо демонстрацію порталу клінік для замовника.
  • Проводимо код-рев'ю та оновлюємо залежності у старих проєктах.
  • Збираємо вимоги для нового проєкту від клієнта з ритейлу.

Плани на квартал

  1. Запустити портал для мережі клінік.
  2. Здати мобільний API та передати його на підтримку.
  3. Оновити внутрішню систему моніторингу.
  4. Підготувати нову версію сайту компанії.
  5. Провести два відкриті мітапи для спільноти.
